# Logic Pro adapter

Target: MIDI FX / plugin / export bridge.

Logic is macOS-only and has limited safe project-scripting paths for this kind of
external editing. Treat it as a later bridge target.

## Phase 1

- Explore MIDI FX or plugin-based note capture.
- Support MIDI export/import fallback.
- Avoid claiming direct project mutation.

## Product rule

Logic may remain visible as future interchange research, but it is not part of
the JUCE product runtime,
REAPER, Ableton, or Bitwig.
